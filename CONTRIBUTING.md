# Contributing

This repository is the GitHub profile index for [SafetyMP](https://github.com/SafetyMP). [README.md](README.md) lists every public repository and what each one refuses to be.

## Where to send a change

- Profile wording, the repository list, or these community files: open a pull request here.
- Product behavior, docs, or bugs: open the pull request on that repository. The list is in [README.md](README.md).
- Authorization policy: [Healthcare-Data-Exchange](https://github.com/SafetyMP/Healthcare-Data-Exchange), not [healthcare-policy](https://github.com/SafetyMP/healthcare-policy).

Follow the [Code of Conduct](CODE_OF_CONDUCT.md). Report vulnerabilities on the product repository ([Security](SECURITY.md)).
