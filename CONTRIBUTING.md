# Contributing

This repository is the GitHub profile portfolio for [SafetyMP](https://github.com/SafetyMP). [README.md](README.md) highlights selected projects and provides a directory of the public portfolio, including supporting and archived repositories.

## Where to send a change

- Profile wording, the repository list, or these community files: open a pull request here.
- Product behavior, docs, or bugs: open the pull request on that repository. The list is in [README.md](README.md).
- Authorization policy: [Healthcare-Data-Exchange](https://github.com/SafetyMP/Healthcare-Data-Exchange), not [healthcare-policy](https://github.com/SafetyMP/healthcare-policy).

Follow the [Code of Conduct](CODE_OF_CONDUCT.md). Report vulnerabilities on the product repository ([Security](SECURITY.md)).

## Keep the portfolio current

- Check the public default branch, relevant implementation guides, and repository archive status before changing a description. Local work and open proposals are not automatically published capability.
- Explain the problem, what a visitor can try, and the current maturity boundary. Distinguish synthetic demos, local applications, connected services, and production validation.
- Keep the introduction brief and the featured selection focused. Link to each project's setup and evidence instead of duplicating commands, test counts, or changing release details.
- Use descriptive links, accessible image text if images are added, and formatting that works on the GitHub profile as well as the repository. Avoid decorative status badges and third-party statistics widgets.
- Check changed links and rendered Markdown. Include new public projects in the directory and label archived projects explicitly.
- Update the review date and [source notes](docs/portfolio-sources.md) when the inventory is reconciled. Do not advance the date for unrelated edits.

The structure follows GitHub's [profile portfolio guidance](https://docs.github.com/en/account-and-profile/tutorials/using-your-github-profile-to-enhance-your-resume): a clear introduction, selected work, and easy paths to examples and source. Profile pins, biography, and social links are account settings; editing this repository does not change them.
