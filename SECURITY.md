# Security policy

This repository contains the public profile and portfolio documentation. It has no application code or deployed service.

For a vulnerability in a linked project, open that project's `SECURITY.md` and follow its current private reporting instructions. The [portfolio directory](README.md) links to the owning repositories, including Agentic Process Safety and Commerce Reliability Kit. Reporting channels and supported versions are maintained by each project.

Do not include undisclosed vulnerabilities, credentials, personal information, or real operational data in public issues or pull requests. Ordinary profile wording and broken-link corrections belong in this repository's profile issue form.

Conduct reports follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
